1. Run npm ci, npm test and npm run evidence from a clean copy on another member's machine.
2. Each member reviews the assigned service and another member's service, makes genuine changes or verification commits, and confirms the contribution table and individual reflection.
3. Edit SeatFlow_Design_Report.docx. Fill the repository, final video and Google Drive links in Appendix D. Export to PDF after review. The report main body has 13 numbered pages before the appendices.
4. Use the silent nine-minute video and the separate speaking script. Record four audio segments aligned with 00:00, 02:15, 04:30 and 06:45. Mix them with the silent recording. Each member speaks for approximately 2 minutes 15 seconds. Final video must remain between 8 and 10 minutes.
5. Publish the source to a GitHub repository that faculty can access. Publish the final narrated video and documents to Google Drive or the required host, verify viewer access, and insert the actual links in the report.
6. Submit repository link, PDF report and final video link. Keep the editable DOCX as the source.
